# Jenisys3-Fixed

基于 Jenisys3 源码编译的修复版本，补全了缺失的依赖和配置文件，可直接运行。

---

## 📌 原项目

- 源码来源：[Jenisys3](https://github.com/FrontierDevs/Jenisys3)
- 基于 Nukkit 修改，使用 LGPL-3.0 协议

---

## 🔧 修复内容

- 补全了运行所需的依赖（Guava、Gson、SnakeYAML、JLine、Netty、OSHI、LevelDB 等）
- 补全了 `lang/` 语言文件
- 提供了默认的 `nukkit.yml` 配置文件
- 可直接运行，无需手动配置

---

## 🚀 使用方法

1. **准备文件**：确保以下文件在同一目录下：
   - `Jenisys3.jar`（服务端核心）
   - `start.bat`（启动脚本，可选）

2. **启动服务器**：
   - 双击 `start.bat`，或在命令行中执行：
     ```bash
     java -jar Jenisys3.jar
     ```

4. **选语言**：
   - 当控制台显示
